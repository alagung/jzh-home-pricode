# 模拟测试文档

本文档用于记录系统功能的模拟测试过程，验证产品流程设计的可行性。

## 1. 测试目标
- 验证从角色设定到一键发布的完整流程
- 测试双版本内容生成（漫画+听书）的协同性
- 确认AI生成内容的质量与一致性
- 发现潜在的用户体验问题

## 2. 测试环境配置
- **图像引擎**：Flux.1-dev (模拟API)
- **文本引擎**：LLM提示词生成器 (模拟)
- **音频引擎**：TTS语音合成 (模拟)
- **视频合成**：FFmpeg自动化脚本 (模拟)

## 3. 标准测试流程

### 步骤 1: 角色设定
用户选择/创建角色 → 系统加载参考图 → 确认可用道具库

### 步骤 2: 内容创作
输入故事主题/选择热门故事/课本同步 → 系统匹配知识库 → 生成长短双版本剧本

### 步骤 3: 参数配置
设置分镜数量、配音音色、视觉风格 → 生成提示词待确认

### 步骤 4: 预览与修订
查看分镜草图、试听配音 → 修改台词/重绘某帧/调整音色

### 步骤 5: 批量生成
正式生成高清图片、合成视频与音频文件

### 步骤 6: 发布配置
选择目标平台（抖音/微信/B端设备）→ 自动适配格式 → 定时/立即发布

    ### 《猫警长新编·哪吒闹海：智斗龙王》

    **第一章：海边巡逻**
    在一个阳光明媚的早晨，猫警长像往常一样戴着他的警帽，沿着东海边巡逻。这片海域最近不太平静，渔民们反映夜里总能听到奇怪的轰鸣声。猫警长竖起耳朵，敏锐地捕捉到海浪中夹杂着一丝不寻常的气息。“不好，有妖气！”他自言自语道，握紧了腰间的警棍。

    **第二章：龙王挑衅**
    突然，海面波涛汹涌，一个巨大的浪花翻卷而来，从中现出一个身穿金甲的少年——龙王三太子敖丙。他手持长枪，傲慢地看着猫警长：“哪来的野猫，敢管我东海龙宫的事？”猫警长毫不畏惧，挺直腰板：“我是这一带的治安官，任何危害百姓安全的行为，我都不能不管！”

    **第三章：激烈对决**
    敖丙冷笑一声，挥枪便刺。猫警长灵活地闪身躲过，同时从腰间掏出一件闪闪发光的法宝——那是太上老君赠予的“正义之光”。只见光芒一闪，化作一条红色的混天绫，紧紧缠住了敖丙的长枪。两人在海浪中你来我往，打得难解难分。海浪拍打着礁石，发出“轰！啪！”的巨响。猫警长一边战斗，一边喊道：“休要放肆！你扰乱海域安宁，今日定要让你知道法律的威严！”

    **第四章：正义胜利**
    经过一番激烈的较量，猫警长凭借智慧和勇气，终于制服了敖丙。他严肃地对敖丙说：“力量不是用来欺负弱小的，而是要用来保护大家。你父亲龙王也一定不希望看到你这样胡作非为。”敖丙低下了头，认识到了自己的错误。海面渐渐恢复了平静，远处的渔民们欢呼起来。夕阳西下，猫警长站在岸边，向百姓们敬礼致意。他的身影在金色的余晖中显得格外高大。“正义必胜！”这是猫警长不变的信念。

    **📚 文化小知识**：
    - 故事原型：《哪吒闹海》是中国经典神话，出自《封神演义》。
    - 传统精神：体现了见义勇为、惩恶扬善的中华美德。
    - 思考题：如果你是猫警长，你会怎么劝说龙王三太子？

    *(全文约 850 字，适合 5-8 分钟音频录制)*
